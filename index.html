③ Registrar equipo (reportante)

El personal escanea el QR → se abre esta misma app en modo GPS → INICIAR → acepta ubicación. Cada equipo queda identificado con ID único + nombre + Gmail/teléfono/IMEI (opcionales, se llenan una sola vez).

Cascada de posicionamiento: GPS (±5-25 m) → si falla, SIM/antenas + WiFi (triangulación tipo Google Maps, ±30-2000 m; la app la etiqueta según la precisión recibida). El navegador no puede leer IMEI/MAC automáticamente: se registran manualmente o se usa el ID único generado. Requiere https y permiso de ubicación.
